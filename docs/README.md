# 燧垒 FlintKeep · 文档

> 本地加密的「基础设施凭证 + 资产清单」管理工具。

## 三句话说明白

1. **凭证只在本地加密存储**：主口令不落盘，解锁后才签发会话凭据，锁定即吊销会话、断开代理与 SSH 堡垒。
2. **落盘无明文**：密码、私钥、令牌都以密文形式保存；界面默认脱敏，显式要求才出明文并记审计。
3. **Agent 不能绕过界面读库**：通过 MCP 访问凭证时受白名单与权限开关约束，执行类工具默认关闭。

## 安装与运行

```bash
npm install
npm run desktop        # 桌面端（推荐）
npm run dev            # 浏览器：8790（前端）+ 8787（后端）
npm run core:test      # 全量自测
```

首次运行会要求设置主口令；口令遗失无法找回，请同时生成并离线保存应急包。
