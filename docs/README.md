# FlintKeep

本地加密的凭证与资产清单管理工具。所有凭据存在本地，用主口令派生的密钥加密，不联网、不上传。

## 能做什么

- 管服务器、SSH 密钥、云账号、对象存储、面板、API 密钥、登录账号，资产类型可以自己加
- 资产之间能关联，比如服务器挂一把 SSH 密钥，连接时直接取用
- 密码、私钥、令牌落盘就是密文；列表默认脱敏，看明文要单独点，点一次记一次审计
- 通过 MCP 服务或 `fk` 命令行把凭证交给 Agent 用，它能看什么由白名单和开关决定
- 密钥轮换提醒、条目版本历史、每日加密备份、从 1Password / Bitwarden / Chrome / KeePass 导入

## 安装

```
npm install
npm run desktop
```

只想开浏览器也行：`npm run dev`，前端 8790、后端 8787。

第一次启动会要求设置主口令。口令不保存，丢失后只能用应急包恢复，所以设完顺手把应急包导出来，离线存好。
