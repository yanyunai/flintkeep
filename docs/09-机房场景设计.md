## 2. 我们的设计（差异点）

### 2.1 设备解剖（项目 = 设备）
```
┌───────────────────────────┐
│ ● LED    项目名      v1.2 │  ← 状态灯=真实探测；悬停整卡
│ ▓▓▓▓▓▓▓░░░░  进度 62%     │  ← 开发中项目：进度壳（服务器逐台装满）
│ [SSH] [面板] [前端] [云] +2│  ← 动态按钮排（见 2.2）
└───────────────────────────┘
```

### 2.2 动态按钮排（核心改进：3 个 → 按关联自动生成，最多 4 + 溢出）
优先级：SSH 真连（关联 server）→ 面板（baota）→ 前端（urls.web）→ 后端（urls.api / server 复用）→ 数据库（urls.db）→ 云控制台（cloud）→ 溢出「+N」弹出其余（仓库/部署/收款/统计/文档/设计稿 + 全部关联资产）。
- SSH 按钮 = 签发堡垒令牌并复制 ssh 命令（我们独有）
- 每个按钮右上角小圆点表示该入口健康状态（最近探测结果）

### 2.3 悬停卡增强（在他们的结构上加我们的数据）
```
┌────────────────────────┐
│ [头像] 项目名  v1.2     │
│ ● 运营中 · 客户名       │
│ 描述一句话…             │
│ ┌─────┬─────┬─────┐   │
│ │¥3.2k│ 1.2万│ 正常 │   │  ← 本月收入 / 用户 / 服务(真实TCP)
│ └─────┴─────┴─────┘   │
│ 关联：服务器2 · SSH1 · 密钥3 · 证书2 ⚠1 │  ← 我们独有：资产关联摘要+到期预警
│ [详情] [SSH 连接] [记一笔] [新任务]     │
└────────────────────────┘
```

### 2.4 点击设备 → 项目抽屉（六页签）
概览（状态/进度/里程碑）· 资源（关联资产分组 + 一键连接）· 入口（URL 十类编辑）· 收支（列表+记一笔）· 任务（迷你看板）· 证书（关联 doc + 到期）。

### 2.5 空机位交互
点击空机位 → 「新建项目」三步向导（形态 → 名称/种类/状态 → 关联资源可跳过）→ 设备落到该机位。机位顺序存 project.seat。

### 2.6 第六视图「安全」
设备按安全状态着色：证书 30 天内到期 / 待换密 / 白名单同步失败 / 端口探测不通 —— 我们独有（数据都在燧垒里）。

### 2.7 深色模式
场景双主题绘制（SVG fill 走令牌）；深色 = 暗机房（黑底 + 霓虹 LED），浅色 = 亮机房。

### 2.8 外部参考采纳
- **Rackula**（拖拽机架设计器）：机位拖拽/导出交互范式
- **Uptime Kuma**：状态语义（up/down/慢）与心跳点阵——设备上的端口 LED 排 + 健康视图心跳线
- 状态页类项目：悬停卡"最近 7 天心跳条"可搬到健康视图

## 3. 技术要点
- 自绘 SVG：设备/机柜/操作台/大屏全部 token 化（fill=var(--x)），深浅一次成型
- 数据源：直接读燧垒 projects（S1 产物）+ /api/studio/check 探测缓存
- 悬停卡/抽屉复用我们现有 Vue 组件体系，不依赖他们的 DOM
