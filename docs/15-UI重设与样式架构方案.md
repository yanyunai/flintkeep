# 15 · UI 重设与样式架构方案

> 前置：`docs/14-统一应用改造规划.md`
> 结论先说：**要重设，但不是推倒重来**。业务逻辑、数据模型、安全模型全部不动，换的是「样式架构 + 视觉语言 + 页面组织」。

---

## 一、为什么现在看着难受（实测数据，不是感觉）

`src/renderer/App.vue` 一个文件 **6915 行**，同时装着：页面模板、业务逻辑、2 个 `<style>` 块。

| 指标 | 数值 | 意味着什么 |
|---|---|---|
| `!important` | **72 处** | 样式互相打架，只能靠暴力优先级压 |
| 硬编码颜色 | **344 处** | 没有 token 层，改一个色要全局搜索 |
| `backdrop-filter` | **33 处** | 玻璃效果滥用，层级全糊，看着"脏" |
| `.chips button` 规则 | 定义了 **6 次** | 同一个按钮在不同上下文长得不一样 |
| 单文件行数 | 6915 | 改一处要读一堆，回归风险高 |

**直接后果**：同一颗按钮，在筛选栏、工具栏、弹窗里是三种样子；表格行高、圆角、阴影各处不一致；深色模式下总有几处对不上。这不是审美问题，是**没有分层**：缺 token 层、缺组件层，只有"选择器 + 感叹号"。

昨天那个「＋」按钮被压回白底灰字，就是这套结构的必然产物——scoped 块的 `.chips button[data-v-xxx]` 特异性压过了 `.chips .chip-add`。

## 二、真实使用数据（决定先画哪个页面）

从 8787 实读：

- 资产 **63 条**：`login_account 18`、`api_key 13`、`ssh_key 9`、`cloud_account 8`、`baota 5`、`project 4`、`微信公众号 4`、`server 2`
- `collections.workbench`：`revenue / costs / tasks / docs / ideas / chats` **全部为空**，只有 `settings`（布局配置）有值

两个结论：

1. **工作台那边没有业务数据**，不存在"迁移"负担。那些页面对我们现在只是**视觉参照**。
2. 真正的产品重心是**资产清单 + 详情/表单**。UI 重设的钱要先花在这里，不是先花在收支页。

## 三、要不要重新设计：要，但只换三层

| 层 | 动不动 | 说明 |
|---|---|---|
| 数据 / 安全 / 业务逻辑 | ❌ 不动 | `vault.enc.json`、AES-256-GCM、审计、脱敏、MCP —— 这些是产品的骨头 |
| 样式架构 | ✅ 重做 | token → 基础组件 → 页面，替换掉 344 处硬编码和 72 个 `!important` |
| 视觉语言 | ✅ 收敛 | 从"到处玻璃"改成"实体表面 + 细边框 + 单一强调色"，只留 1–2 处记忆点 |
| 页面组织 | ✅ 拆分 | `App.vue` 拆成 `views/` + `ui/`，一个页面一个文件 |

**不建议**整体推倒重写：机房页上次就是这么失败的——重写范围过大，没有可比对基线。这次按页切片，每页都有"切回旧版"的开关。

## 四、视觉方向（三选一，我推荐 A）

### A. 克制型高密度 SaaS（推荐，对标 `twenty` / `plane` / `linear`）

- 实心表面 + 1px 细边框，**不用 backdrop-filter**（只在侧栏和弹窗保留一处）
- 阴影只用于"浮起来"的东西：弹窗、抽屉、hover 卡片；表格行不加阴影
- 单一强调色 `--accent: #2f7ff0`，其余靠灰阶分层
- 数字一律 `tabular-nums`，表格右对齐
- 圆角三级：`6 / 10 / 14`，**不再用 999px 满世界药丸**

适合：63 条资产的密集表格、8 种类型的筛选、每天要看很多遍的详情页。

### B. 高级财务感（对标 `maybe`）

大留白、衬线标题、极克制的双色。好看，但**信息密度低**——63 条资产要翻很多屏。适合做官网，不适合做工作界面。

### C. 保留现在的玻璃拟态，只做收敛

改动最小，但你已经在抱怨它了，收敛后大概率还是"没那么爽"。

> 建议：**主界面走 A，官网/引流页走 B**。两套视觉不冲突，因为它们本来就该是两种气质。

## 五、Token 体系（先落地这一层，后面才有得谈）

新建 `src/renderer/ui/tokens.css`，只允许它出现颜色字面量：

```css
:root {
  /* 表面：三层，够用且不糊 */
  --bg:            #f7f7f8;
  --surface:       #ffffff;
  --surface-2:     #fafafa;
  --surface-3:     #f2f3f5;

  /* 边框：只用两级 */
  --border-subtle: rgba(0,0,0,.07);
  --border-strong: rgba(0,0,0,.14);

  /* 文字：三级 */
  --text:   #17181a;
  --text-2: #5b5f66;
  --text-3: #8b9098;

  /* 强调与语义 */
  --accent:  #2f7ff0;
  --success: #1a7f37;
  --warn:    #b26a00;
  --danger:  #cf222e;

  /* 圆角三级 */
  --r-sm: 6px;  --r-md: 10px;  --r-lg: 14px;

  /* 间距：4 的倍数 */
  --s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px; --s-5: 24px; --s-6: 32px;

  /* 阴影：只留一级 */
  --shadow-pop: 0 8px 24px rgba(16,24,40,.10), 0 1px 2px rgba(16,24,40,.06);

  /* 字号 */
  --f-xs: 11.5px; --f-sm: 12.5px; --f-md: 13.5px; --f-lg: 15px; --f-xl: 20px; --f-2xl: 28px;
}
[data-theme='dark'] { /* 同名变量整体替换，页面代码零改动 */ }
```

规则（写进 `docs/design/README`）：

1. 组件样式里**禁止**出现 `#` 开头的颜色，只能用变量
2. **禁止** `!important`，除非覆盖第三方（本项目没有第三方 UI）
3. 选择器**不超过两层**，不再用后代选择器去改子组件
4. 组件样式一律 `<style scoped>`，全局样式只放 `tokens.css` + `base.css`

## 六、组件清单（12 个，先做这 12 个就够撑起主界面）

| 组件 | 关键点 | 现在的问题 |
|---|---|---|
| `Btn` | 5 种变体 × 3 尺寸，统一高度 28/32/36 | 现在每处自己写 padding |
| `Input` / `Textarea` | 统一高度、focus ring、错误态 | 高度不一 |
| `Select` | 原生 select 美化 + 自定义下拉两版 | 混用 |
| `Tag` | 类型标签复用，含自定义色自动对比 | 已修过，收进组件 |
| `Card` | 表面 + 细边 + 可选 header | 各处阴影不一 |
| `Table` | 定宽列、行高 44/48、hover、空态、骨架 | 上次刚修，需沉淀 |
| `Drawer` | 右侧详情抽屉（替代现在的整页跳转） | 现在没有 |
| `Modal` | 统一头/体/脚，含 ESC 与焦点陷阱 | 各弹窗各写一套 |
| `Toast` | 替代 `alert()` | 现在还有 alert |
| `EmptyState` | 图标 + 一句人话 + 主按钮 | 各处文案不同 |
| `CommandPalette` | `Cmd+K` 全局搜索资产/命令 | 无，但强烈建议加 |
| `FieldRow` | 表单一行：label + hint + 控件 + 校验 | 现在 label 手写 |

交互原语（弹窗焦点、下拉定位、键盘导航）用 **Reka UI 2.11** 的无样式组件，样式仍自己写。**不引 shadcn-vue**（带 Tailwind，会跟这套 CSS 打架）。

## 八、和"去掉 iframe"的关系

一个必须说清的技术事实：**机房没法单独留**。`openOpc('studio')` 是在 iframe 里切到 OPC 那个单文件应用的 `#/studio` 页——要跑机房，就得整个 旧版应用跑起来。

所以过渡期只能这样：

- iframe **保留但收窄**：只服务「机房」一个入口，其他页面全部自己写
- 桥接代码跟着砍：现在 `wb*` 要把 OPC 所有页面数据同步进 vault；只剩机房后，只需要同步 `settings.studio / rows / cols` 这几个布局字段，**桥接量能砍掉八成**
- 机房复刻完成（SVG 机柜场景 + 状态灯 + SSH 状态）→ 整个 `旧版工作台/` 删除

顺带：`旧版工作台内嵌页/LICENSE` 是「个人免费、商用需授权」，而你打算开源。**收窄 iframe 的同时正好把它从公开仓库摘出去**，一举两得。
