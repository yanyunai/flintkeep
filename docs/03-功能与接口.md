# 03 功能与接口

## 资产类型（AssetType）

`server` / `ssh_key` / `cloud_account` / `oss` / `baota` / `mcp` / `api_key`（API/模型密钥）/ `login_account`（登录账号：手机号/邮箱/密码）

资产可互相 `links` 关联（角色如 SSH 密钥、宝塔、登录账号等）；服务器关联 SSH 密钥时会同步 `sshKeyId` 供堡垒使用。

SSH 密钥支持上传 OpenSSH 私钥文件：正文进燧垒，并在 `data/ssh_keys/<id>.key.enc` 存加密副本（非明文）。`get_server_connection` 在已关联密钥时会附带 `privateKeyEnc`，供 Agent 使用；更推荐 `request_ssh_access`。

关键字段见 `schema.ts`：服务器含 `ip / sshPort / openPorts / authMethod / sshUser / sshPassword / sshKeyId`；SSH 密钥含 `publicKey / privateKeyEnc / keyPassphrase`；云 / OSS 含 `provider / accessKeyId / secretAccessKey / region / cloudService / cloudVersion`；宝塔含 `panelUrl / baotaUser / baotaPassword / baotaApiKey`；MCP 含 `transport / command / args / envEnc`；通用含 `username / secret`。所有类型共含 `rotationReminderDays / lastRotatedAt` 与代理注入字段 `baseUrl / proxyInject`。

## 功能清单

- 多类型资产增删改查（可视化界面）；支持自定义资产类型（`/api/asset-types`）
- 列表 / 搜索脱敏；详情可切换显示敏感字段
- 密钥轮换提醒（界面「⚠ 待换密」标 + 「待轮换」筛选）
- 条目版本历史：每次更新/删除/回滚留一版（每资产 10 版、全库 300 版上限），可回滚；已删除资产不可回滚
- 加密备份 / 恢复（verifier 校验，错口令拒绝不覆盖；导入先试解后落盘）
- 每日自动加密备份（`settings.dailyBackup`，默认开，保留 7 份）
- 备份导入器：1Password CSV / 1PUX、Bitwarden、Chrome、KeePass，先预览再提交（去重按 `dedupeKey`）
- MCP stdio 接入 + 审计（含调用方）；令牌模式（`FK_TOKEN`）只下发 3 个工具
- Agent 自报操作审计（`log_agent_action`）
- **命令行 `fk`**：status / list / show / connect / env / inject / agent / token（见 02「CLI」）
- **本地 SSH agent**：`ssh` / `git` / `scp` 直接用保险库里的私钥，签名前过锁屏策略
- **访问令牌（服务账号）**：`fksa_` 令牌给 CI/脚本用，scope + caps + 有效期，撤销立即生效
- Model B HTTP 代理注入（header / basic / baota / AWS SigV4 / 阿里云 RPC / 腾讯云 TC3）
- Model B SSH 会话代理（本地堡垒，`ssh2`）；会话收尾写 `ssh_exec` / `ssh_session` 审计（命令摘要脱敏、时长、成败）
- 审计：分页查询、保留策略可配置、原文 JSONL 导出（含历史代）
- 界面：备份导入导出、详情签发 HTTP/SSH 代理、表单配置 `baseUrl` / `proxyInject`
- 界面「MCP 接入」页：通用「给 Agent 的话」/ 通用 stdio 配置片段（含本机绝对路径，适配任意 MCP 客户端）
- 界面「模型用量」页：云账号的余额 / 消费 / 资源包 / 模型清单 / **免费额度**（含到期、单位、重置、用完即停）
- 字段管理：内置字段定义在 `src/core/builtin-fields.ts`，设置页可改显示名/列/表单显隐；自定义字段存 `data/field_schema.json`，值落 `asset.extra`，参与展示与搜索。列配置 `/api/column-config` 每个资产 tab 独立选择列（上限 20），类型颜色仍由 `/api/field-catalog` 维护
- 白名单模块（IP 白名单执行与审计）：阿里云**前缀列表** + 腾讯云**地址模板**，地域 / 目标 ID 自动下拉
- 资产管家（`/api/assistant/*`）：应用内口语指令智能体，可读可写，写操作需确认；支持 SSE 流式
- 运行工作台（`/api/myprojects/*`）：项目登记 / 启停 / 状态 / 统一监控
- 备忘录（`note` 类型资产）

## 设置项（`settings.json`）

| 键 | 默认 | 作用 |
|---|---|---|
| `agentPermission` | `normal`（新装） | `normal` 只能读与连；`full` 才允许 `manage` 写、执行类工具 |
| `allowLockedAccess` | `false` | 锁屏后是否仍允许 Agent 读取（默认锁定即断开） |
| `allowAgentExec` | `false` | 是否向 Agent 暴露执行类工具（启动项目、白名单执行等） |
| `proxyAllowHttp` | `false` | 代理是否允许 http 上游（默认只 https） |
| `dailyBackup` | `true` | 每日自动加密备份 |
| `mcpFullTools` | `false` | MCP 是否下发完整 36 工具（否则 9 个入口） |
| `sshAgent` | `false` | 本地 SSH agent 开关（解锁启动、锁定停止） |
| `auditMaxMB` / `auditKeepGenerations` | `5` / `3` | 审计保留策略 |
| `autoLockMinutes` | `15` | 无操作自动锁定时长 |
| `closeAction` | `background` | 关窗行为（后台常驻 / 退出） |
| `lang` | `zh` | 界面与后端错误文案语言 |

## REST API

路由按关注点分模块：会话与安全在 `security-routes.ts`，资产与备份在 `assets-routes.ts`，运维类在 `ops-routes.ts`，白名单在 `whitelist-routes.ts`，资产管家在 `assistant-routes.ts`，模型用量在 `ai-usage-routes.ts`；`server.ts` 只保留 Host 校验、免会话区、解锁门与分发。**请求顺序即安全语义**（见 02）。

### 模型用量（`/api/ai-usage/*`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ai-usage/config` | 读配置（探测间隔、账号、CLI Profile 绑定） |
| PUT | `/api/ai-usage/config` | 改配置 `{probeIntervalHours, autoProbe, accounts}` |
| GET | `/api/ai-usage/cli-status?check=1` | 自检本机百炼 CLI：是否安装 / 是否登录 / 调用是否通；不通时返回 `fix` 修复命令 |
| GET | `/api/ai-usage/profiles` | 百炼 CLI 的 Profile 列表及各自登录身份（供多账号绑定）。带 `?accountId=` 时额外返回每个 Profile 的 `match`（是否属于本账号）、`matchBy`（`apiKey` / `workspace`）、`boundTo`（已被哪个别的账号绑定），以及 `suggest` 推荐项 |
| POST | `/api/ai-usage/bind` | 把 Profile 绑定到云账号 `{accountId, profile}`；`profile` 为空即解绑 |
| GET | `/api/ai-usage/snapshot` | 某账号的快照 `?accountId=` |
| POST | `/api/ai-usage/refresh` | 拉取全量 `{accountId, probe?, force?}`。**默认不探测**（不消耗额度）；距上次 <60s 返回 429，`force:true` 可绕过 |
| POST | `/api/ai-usage/probe` | 手动探测（真实调用模型，消耗额度） |
| POST | `/api/ai-usage/freetier` | 开/关「免费额度用完即停」`{model\|all, on, accountId}`。**未绑定 Profile 时拒绝**（防改错账号） |

数据源：余额/消费/账单/资源包走阿里云 BssOpenApi；模型清单走 DashScope `/api/v1/models`；**免费额度只能走百炼官方 CLI `bl`**（模型清单 API 无额度字段，无公开额度 API）。

**账号归属是严格的**：某个云账号只有绑定了属于自己的 CLI Profile 才拉取额度；未绑定则该账号页面不显示任何额度（哪怕有历史残留也会清空），只给「去绑定 / 添加 CLI 身份」入口。判定依据优先级：CLI 身份里的 API Key 掩码与本账号吻合 > 业务空间 ID（`ws-xxx`）一致。

**取数失败不清空**：CLI 报错（如控制台令牌失效 `BailianGateway.Team.NotAuthorised`）会原样显示在页面上并给出修复命令，同时保留上一次的数据并标记 `quotaStale`，不再静默变成 0。

**刷新并发**：免费刷新最多 3 个账号并行；探测（真实调用模型、花额度）保持串行。配置与价目是共享文件，写入走文件锁，绑定关系用「锁内重读 + 合并」更新，不会被并发刷新覆盖。

## 本地 SSH agent（`src/core/ssh-agent.ts`）

把「SSH 登录」资产（`ssh_key`）里的私钥做成标准 agent，普通 `ssh` / `git` / `scp` 直接可用，私钥不出本进程。

| 入口 | 说明 |
|---|---|
| 设置 → 安全 → 「本地 SSH agent」 | 开关 `settings.sshAgent`（默认关）。解锁即监听、锁定即停止；改开关即时生效 |
| `fk agent` | 前台运行（需口令，Ctrl+C 停止并清 socket） |
| `fk agent env` | 只输出一行 `export SSH_AUTH_SOCK="…"`，可 `eval "$(fk agent env)"` |
| `fk agent status` | 免口令查询是否在跑、有几把密钥（走 socket 的 REQUEST_IDENTITIES） |

协议子集：`REQUEST_IDENTITIES` / `SIGN_REQUEST`（ed25519、RSA 的 `rsa-sha2-256/512` 与 `ssh-rsa`、ECDSA p256/384/521）；`ADD/REMOVE/LOCK/EXTENSION` 一律返回 `SSH_AGENT_FAILURE`——密钥来源只有保险库，agent 不提供写入面。

约束：socket 落在数据目录 `agent.sock`（0600，目录 0700，路径 ≤ 100 字符）；每次签名先过锁屏策略（与 MCP/REST 同一套 `lock_state.json` + `allowLockedAccess`），拒绝与被拒都写审计（`agent_sign` / `agent_sign_denied` / `agent_key_invalid`）；陈旧 socket（文件在但无人监听）自动清理，两个 agent 抢同一路径时发起方报错。

## MCP 工具（mcp.ts）

默认下发 **9 个任务导向入口**（`tools/list` 约 4.5 KB）：

| 工具 | 用途 |
|---|---|
| `find` | 按关键字/类型/标签找资产；卡片化 + 分页（`limit` 默认 20、`nextOffset`），支持 `fields` 投影 |
| `show` | 看单个资产；默认脱敏，`reveal=true` 才返回敏感字段（写审计），支持 `fields` |
| `connect` | 所有资产类型一个入口：server/ssh_key → SSH 堡垒命令；cloud/oss/baota/api_key → 代理基址 + 令牌；mcp → 启动命令；login/email → 账号信息 |
| `manage` | 增 / 改 / 删资产；`delete` 需 `confirm=true`，否则返回 `needsConfirm` |
| `run_project` | 项目启停与状态（受「全自动」档位 + 执行开关约束） |
| `sync_whitelist` | 白名单同步（同上） |
| `usage` | 模型用量查询 |
| `note` | 备忘录读写 |
| `backup` | 导出 / 导入备份（`import` 受档位约束） |

- `connect` 的 `target` 支持 id、名称、`类型:序号`（如 `server:3`）、唯一纯序号、唯一模糊命中，不必先查 id。
- 响应为紧凑 JSON；错误统一 `{code, error, hint?, next?}`，按 `next` 纠错。
- `initialize` 返回 `instructions`：连接类 1 次调用、不要枚举、看密码需 `reveal`。
- 老工具（27 个：`list_assets` / `search_assets` / `get_asset` / `get_server_connection` / `add_asset` / `update_asset` / `delete_asset` / `log_agent_action` / `export_backup` / `import_backup` / `request_proxy_access` / `request_ssh_access` 等）**全部保留可调用**，默认不进 `tools/list`。需要字段 / 类型 / 集合级能力时开全量：设置页「MCP 下发完整工具集」，或环境变量 `FLINTKEEP_MCP_PROFILE=full`（约 22 KB / 36 个工具）。
- 回归基线：`npm run mcp:baseline`，指向数据目录副本并传 `VAULT_PASSPHRASE`，记录 5 个固定任务的调用次数与响应字节，超标非零退出。

MCP 为 stdio 服务，无法交互输口令，从 `VAULT_PASSPHRASE` 读（首次运行即初始化口令）。

## 运行

```bash
npm install
npm run typecheck       # tsc --noEmit（含 server.ts 与 tests）
npm run lint            # ESLint（flat config，vue essential）
npm run i18n:check      # 文案键一致性
npm test                # Vitest：16 个文件 149 例（确定性核心，含 CLI 与 SSH agent）
npm run test:legacy     # 环境探针：CLI 真实调用、TC3 真签名、MCP stdio 子进程（需本机条件）
npm run smoke:http      # HTTP 回归基线（56 项：锁态矩阵 / 解锁门 / 资产 / 令牌 / ssh-agent）
npm run mcp:baseline    # MCP 工具面预算（tools/list ≤ 5000 B、5 个任务 ≤ 6 次调用）
npm run smoke:server    # 锁态 API 冒烟
npm run smoke:memo      # 备忘录冒烟（11/11）
npm run smoke:whitelist # 白名单冒烟（19/19）
npm run fk -- list      # 命令行（需 FK_PASSPHRASE / FK_TOKEN）
npm run dev             # 前端 8790 + 服务 8787（+8788 HTTP / +8789 SSH）
npm run desktop         # 桌面客户端（推荐：自动清理残留后端，改完代码重启即生效）
npm run dev:electron    # Electron + Vite 开发窗
npm run start:electron  # build 后 Electron 预览
```

CI（`.github/workflows/ci.yml`）在 push `main` / `feat/**` 与 PR 上跑：typecheck → lint → i18n:check → `npm test` → `smoke:http`。

### 模型用量的前置条件

免费额度依赖百炼官方 CLI（已作为 devDependency 引入，命令 `bl`）：

```bash
bl auth login --console              # 首次：浏览器登录（走控制台 access_token）
bl auth login --console --config profile-2   # 第二个阿里云账号：登录到独立 Profile
```

之后在页面「模型用量 → CLI 身份」下拉里把 Profile 绑定到对应云账号。**未绑定不拉额度**，避免把 A 账号的额度显示到 B 账号页。

**给新账号添加 CLI 身份**（页面内「＋ 为『账号名』添加 CLI 登录身份」按钮会给出 4 步引导，命令可直接复制）：

1. 页面先填好该账号的 API Key（可选，仅用于之后判断「哪个 Profile 属于本账号」）
2. 复制生成的命令：`bl auth login --console --config <自定义Profile名>`
3. 在**终端**执行 → 浏览器里登录那个阿里云账号（浏览器登录必须在终端做，应用内拉不起来）
4. 回页面点「我已登录，刷新身份列表」→ 选刚出现的 Profile → 绑定

注意：CLI 是**单登录态 + 多 Profile** 结构，第二个账号必须登录到独立 Profile，不能覆盖默认身份；所有 Profile 都存在同一个 `~/.bailian/config.json` 里（`--config` 只是切换，不是另一个文件）。控制台 access_token 会过期，过期后页面会提示 `bl auth login --console`（此时**用 AK/SK 重新生成 token 无效**，必须重新走浏览器登录）。

### 端口与残留进程

后端默认 `8787`。改完 `server.ts` / `src/core/*.ts` **只需重跑 `npm run desktop`** —— 启动器会自动清掉上一轮残留的后端进程（只清确认属于本应用的，不会误杀别的软件）。

- 端口被其它程序占用：启动时会明确提示，可换端口
  - macOS / Linux：`PORT=8799 npm run desktop`
  - Windows：`set PORT=8799 && npm run desktop`
- 想在别的终端保留 `npm run dev`：`KEEP_EXISTING_BACKEND=1`（Windows 用 `set` 同上）
- 手工清理
  - macOS / Linux：`lsof -nP -iTCP:8787 -sTCP:LISTEN` → `kill <PID>`
  - Windows：`netstat -ano | findstr :8787` → `taskkill /PID <PID> /F /T`
